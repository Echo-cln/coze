# WF40_Outline_Write 接口调用文档

## 1. 接口地址

| 环境 | Base URL | 说明 |
|---|---|---|
| 本地开发 | `http://localhost:5000` | `bash scripts/http_run.sh -p 5000` 启动（端口可用 `-p` 自定义，部署环境由 `DEPLOY_RUN_PORT` 注入） |

**可用端点**（均以 Base URL 为前缀）:

| 端点 | 方法 | 用途 |
|---|---|---|
| `/run` | POST | **同步执行**，阻塞至完成，一次性返回完整结果（超时上限 900 秒） |
| `/stream_run` | POST | **SSE 流式执行**，`text/event-stream`，可实时观察进度 |
| `/async_run` | POST | 异步执行，立即返回 task_id |
| `/task/{task_id}` | GET | 查询异步任务状态/结果 |
| `/node_run/{node_id}` | POST | 单节点调试（如 `section_plan`、`assemble`) |
| `/graph_parameter` | GET | 在线查询本图的入参/出参 JSON Schema |
| `/cancel/{run_id}` | POST | 按 run_id 取消执行 |
| `/health` | GET | 健康检查 |

## 2. 鉴权方式

- **本地/直连：无鉴权**。服务代码未内置任何 token / API Key 校验，直接请求即可。
- **平台部署后**：访问控制由平台网关统一托管（产物发布后按平台提供的调用凭证/环境隔离访问），工作流代码无需改造。
- **可选 Header**（非鉴权，但建议）:

| Header | 作用 |
|---|---|
| `Content-Type: application/json` | 必填，Body 为 JSON |
| `X-Run-ID: <自定义ID>` | 指定运行 ID，便于日志追踪和 `/cancel/{run_id}` 精确取消 |
| `x-workflow-stream-mode: debug` | 仅 `/stream_run`：开启后推送节点级 `node_start`/`node_end` 事件 |

## 4. 出参事件 / 字段

### 4.1 `/run` 同步返回（application/json)

| 字段 | 类型 | 说明 |
|---|---|---|
| `section_drafts` | array | 8 个章节草稿，每项含 `section_id`/`title`/`markdown`（带 `[E000xxx]` 占位符）/`used_evidence_ids`/`used_conflict_ids`/`open_questions` |

| `run_id` | string | 本次运行 ID（服务层附加） |

### 4.2 `/stream_run` 流式事件（SSE)

格式为标准 SSE(`event: message` + `data: {JSON}`)，每条 data 含 `type`/`timestamp`/`log_id`/`run_id`。事件类型：

| type | 说明 |
|---|---|
| `workflow_start` | 工作流开始 |
| `workflow_end` | 工作流结束，`output` 字段携带与 `/run` 相同的完整出参 |
| `node_start` / `node_end` | 节点级事件（含 `node_name`、输入/输出、耗时 ms),**仅 debug 模式**推送 |
| `ping` | 心跳（30 秒间隔） |
| `error` | 错误事件，`code` 为 `CANCELED` / `TIMEOUT` / 业务错误码 |

## 5. 文件怎么传

**WF40 不直接接收文件——这是架构设计，不是缺失**。

按数据主线，文件在前置工作流中被消费：`文件 → WF10 解析 → WF20 抽取为证据台账 → WF40`。WF40 的输入是**结构化的 JSON 证据台账**，证据原文已经由 `quote` 字段携带，因此调用 WF40 时：

- ❌ 不需要、也不支持传 PDF/DOCX/XLSX 文件或 multipart 表单；
- ✅ 文件内容以 `evidence_ledger[].quote`（原文摘录）+ `locator`（页码/表格定位）的形式进入；
- ✅ 若你目前只有原始文件（如演示数据包），需先经 WF10/WF20（或按 EvidenceItem 契约自行抽取）转成台账后再调用——本次中信证券测试即是此路径。

如果后续需要给 WF40 扩展文件类入参，平台统一的 File 类型传法是 JSON 内嵌 URL 对象：

```json
{"url": "https://<对象存储地址>/xxx.pdf", "file_type": "document"}
```

注意：URL 必须公网可访问（本地文件需先上传对象存储），服务不支持 multipart 文件上传。
